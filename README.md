# Описание применения генеративной модели

Проект: копирование отдельных блоков главной страницы alfabank.ru с последующей адаптацией вёрстки и созданием интерактивных компонентов (меню, табы, подгрузка карточек продуктов).

## Использованные модели

| Модель | Цель применения | Сайт / источник |
|--------|----------------|------------------|
| Claude Code (Anthropic Claude 3.5 Sonnet) | Первичная генерация HTML/CSS на основе скачанного кода, переименование обфусцированных классов, компоновка блоков | доступ через claude.ai |
| DeepSeek (мыслящая версия) | Генерация JSON-файлов (products.json, header.json) по предоставленным HTML-классам и структуре; рефакторинг JavaScript-кода (удаление fetch, создание классов, переписывание логики); помощь в переработке вёрстки для избежания прямого копирования | https://deepseek.com |

## Подробное описание применения

### 1. Начальный этап (Claude Code)
- Скачал исходный HTML-файл с alfabank.ru (со встроенными нерабочими скриптами и обфусцированными классами).
- Отправил Claude Code задание: «скопируй только блоки hero, products, cashback, services, offers, about, а также структуру шапки и футера. Переименуй все классы в понятные человеку. Создай отдельные CSS-файлы».
- Полученные HTML и CSS сохранил как основу.

### 2. Рефакторинг и объединение CSS (ручная правка + DeepSeek)
- Обнаружил, что Claude разбил стили на много мелких файлов – объединил их вручную в один `style.css` через `@import`.
- Некоторые блоки вёрстки не соответствовали макету – поправил вручную (изменил уровни вложенности, добавил недостающие контейнеры).
- Чтобы CSS не выглядел «слепком», попросил DeepSeek переписать часть правил в более лаконичную форму – модель предложила использовать CSS-переменные и убрать дублирование.

### 3. Создание JSON-данных (DeepSeek)
- Для динамического меню и карточек продуктов нужны были структурированные данные.
- Скопировал готовые блоки меню из исходного сайта, отправил DeepSeek скриншоты и текстовые выдержки с просьбой оформить в виде `header.json` по образцу, который дал использовался на парах. Модель корректно распарсила иерархию и сгенерировала JSON.
- Для `products.json` отправил DeepSeek список классов карточек, которые появились после рефакторинга, и попросил придумать заголовки, описания и категории («all», «business», «corp»). Модель быстро сгенерировала 24 варианта продуктов.

### 4. Переработка JavaScript (DeepSeek)
- Изначально в скачанном коде использовался `fetch` для подгрузки JSON, а вся логика была написана в процедурном стиле.
- Чтобы код стал более поддерживаемым и независимым от внешних файлов (задание предполагает локальную работу без сервера), попросил DeepSeek:
    - переписать всё в виде классов (`MenuController`, `ProductsController`, `BurgerManager`);
    - встроить данные прямо в JS (убрать `fetch`);
    - добавить обработку бургер-меню и адаптивную мобильную навигацию.
- Модель выдала готовый `main.js`, который я слегка доработал.

### 5. Финальные правки
- Удалил все следы оригинальных svg-графики, заменив их текстовыми эмоджи (💳, 📈, 🏦 и т.д.).
- Проверил работу всех табов, бургер-меню, мегаменю – что бы всё работало без ошибок.
